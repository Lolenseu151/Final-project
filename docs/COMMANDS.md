# Game Commands & Controls

## Player Controls
The following controls are available for controlling the character:

| Action | Primary Key | Secondary Key | Description |
|--------|-------------|---------------|-------------|
| **Move Left** | `A` | `Left Arrow` | Move character left |
| **Move Right** | `D` | `Right Arrow` | Move character right |
| **Jump** | `W` | `Up Arrow` | Jump (must be on ground) |
| **Dash** | `Space` | - | Perform a quick dash (has cooldown) |

## System Controls
| Action | Control | Description |
|--------|---------|-------------|
| **Pause** | UI Button | Click the Pause icon in the top-right corner to pause the game. |
| **Interact** | Mouse | Use the left mouse button to interact with UI elements (menus, dialogs). |

> [!TIP]
> **Dash Mechanics**: The dash gives you a burst of speed and is useful for clearing gaps or moving quickly. It has a short cooldown (10 seconds) indicated by a timer if active.
